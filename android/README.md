# Cinefilm Archive — اپ اندروید (تلویزیون و گوشی)

یک پوسته‌ی WebView که سایت آرشیو رو تمام‌صفحه نشون می‌ده.

## ساخت APK (یک‌بار)
1. **Android Studio** رو نصب کن (از developer.android.com/studio).
2. **File ← Open** و پوشه‌ی `android/` این ریپو رو باز کن.
3. اولین بار Gradle خودش کتابخونه‌ها و Wrapper رو دانلود می‌کنه (چند دقیقه).
4. **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
5. فایل `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شه.

## نصب روی سونی اندروید TV
- **روش ساده (USB):** فلش USB با APK، روی تلویزیون پوشه‌ی فایل‌ها رو باز کن و APK رو نصب کن (باید «نصب از منابع ناشناس» روشن باشه).
- **روش ادب (ADB):** تلویزیون رو در Developer options و USB debugging روشن کن، بعد:
  `adb connect <IP-تلویزیون>` و `adb install app-debug.apk`
- بعد از نصب، اپ «Cinefilm Archive» تو لانچر تلویزیون (Android TV) ظاهر می‌شه.

## لاگین
- کوکی سشن سایت (۳۰ روز) تو WebView ذخیره می‌شه، پس یک‌بار لاگین کنی، دفعه‌های بعد لازم نیست.
- اگه سشن منقضی شد یا از سایت خارج شدی، دوباره لاگین می‌خواد.

## کنترل با ریموت
- **Back:** برگشت به صفحه‌ی قبل، وگرنه خروج از اپ.
- **Menu:** رفرش صفحه.
- جهت‌ها روی دکمه‌ها و کارت‌های سایت فوکوس می‌برن. اگه بعضی کارت‌ها فوکوس نگیرن، بگو تا با تنظیم ترتیب فوکوس درستش کنم.

## محدودیت‌ها (صادقانه)
- این یک پوسته‌ی وب است، پس سرعتش به سرعت سایت و تلویزیون بستگی دارد.
- نشانگر موس نداره؛ حرکت با ریموت فقط با فوکوس دکمه‌ها.
- لینک‌های بیرونی (IMDb، یوتیوب، Letterboxd) در مرورگر سیستم باز می‌شن.
